# Glitch 2.0 Attendance Logger — copy-paste formulas
# Paste into the matching tab of the spreadsheet (see docs/SETUP.md Step 6).
# Tab names referenced: 'Sign-ins' (form responses), 'Presence Matrix', 'Roster'.

# ---------------------------------------------------------------
# Presence Matrix — A1 header cells
# ---------------------------------------------------------------

# A1 (plain text):
Member

# B1 (header row of practice dates; spills right; format B1:Z1 as Date):
=TRANSPOSE(SORT(UNIQUE(FILTER(ARRAYFORMULA(INT(Sign-ins!$A$2:$A)), Sign-ins!$A$2:$A<>""))))

# A2 (member list; spills down):
=SORT(UNIQUE(FILTER(Roster!$A$2:$A, Roster!$A$2:$A<>"")))

# B2 (fill the grid by dragging the fill handle; Present/Absent per member per day):
=IF(SUMPRODUCT(ARRAYFORMULA(INT(Sign-ins!$A$2:$A)=B$1), ARRAYFORMULA(Sign-ins!$B$2:$B=$A2))>0,"Present","Absent")

# ---------------------------------------------------------------
# Season Summary — headers in row 1
# ---------------------------------------------------------------

# A1 (plain text):
Member
# B1:
Total sign-ins
# C1:
Practice days attended
# D1:
Attendance %

# A2 (spills down):
=SORT(UNIQUE(FILTER(Roster!$A$2:$A, Roster!$A$2:$A<>"")))

# B2 (drag down):
=IFERROR(COUNTIF(Sign-ins!$B$2:$B, $A2),0)

# C2 (distinct practice days with a sign-in; drag down):
=IFERROR(COUNT(UNIQUE(FILTER(ARRAYFORMULA(INT(Sign-ins!$A$2:$A)), Sign-ins!$B$2:$B=$A2))),0)

# D2 (attendance %; drag down; format as percent):
=IFERROR(C2/COUNTA('Presence Matrix'!$B$1:$Z$1),0)
